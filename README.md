# Sistema de Gestión de Pedidos para Restaurante 

Aplicación de escritorio desarrollada en Java con interfaz gráfica (GUI) orientada a simular el flujo de ventas, selección de menú y facturación de un restaurante. 

Este es un proyecto académico enfocado en el manejo de interfaces gráficas con Java Swing, la gestión de eventos de usuario y la manipulación de estructuras de datos para la actualización de tablas en tiempo real.

##  Funcionalidades Principales

*   **Catálogo Interactivo:** Selección visual de platos con controles dinámicos para ajustar las cantidades (+ y -) mediante el uso de ActionListeners.
*   **Carrito de Compras en Tiempo Real:** Visualización instantánea de los productos añadidos, valor unitario y cálculo automático del subtotal utilizando `DefaultTableModel`.
*   **Módulo de Pagos:** Simulación de una pasarela de facturación mediante la gestión de visibilidad de paneles con múltiples métodos de pago integrados (PSE, Tarjeta, Efectivo, QR).
